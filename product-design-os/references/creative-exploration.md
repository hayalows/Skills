# Creative exploration and adaptive effort

Use this for substantial new directions, full redesigns or a screen with an explicit creative brief. Do not force it into a label or spacing fix.

## Effort routing

| Work | Visual effort |
| --- | --- |
| Touch | Inspect the specific problem, check affected gate rules, change, render and regression check. No new brand direction. |
| Screen | One brief, two quick composition options when visual direction is open, one built option, screenshot critique and applicable gates. |
| Flow | Map all states, select one coherent direction; compare meaningful alternatives for high-impact screens. Verify each key state and breakpoint. |
| Product | Explore three distinct directions if the brand allows; choose one, implement a complete vertical slice, critique, then extend. |
| Audit | Inspect, diagnose and rank fixes by task effect. No implementation without permission. |

## Explore genuinely different ideas

Start from real subject materials, audience, environment, use frequency, data and task. Keep the content and assets constant when comparing layouts. Do not call three palette swaps three concepts.

For each direction state: subject-derived signature; opening composition; type and colour; content rhythm below the fold; mobile adaptation; real interaction; constraints and risks. Use quick sketches, small HTML experiments or rough wireframes if available. Compare how quickly the task can be understood, how memorable the subject is, whether the style scales, how it handles real content, and how costly it is to build. Choose based on those tradeoffs, not novelty alone.

Expressive examples: a poster composition, a full-width subject-led stage, an asymmetric editorial arrangement. Utility examples: a compact ledger, a workspace with contextual result, a task-focused step sequence. They are starting points, not templates. Preserve established brand unless the user authorizes change. Do not inject a creative hero into a utility tool.

After selection write a short design contract with a limited type scale, semantic palette, spacing rhythm, purposeful image or data treatment and primary task. Make the same choices visible below the fold. If it is indistinguishable from unrelated templates, revisit the composition, not merely the colours. Use the Visual Integrity Gate and existing product rubric independently. When working alone, label the critique as self-review; do not invent independent reviews or user feedback.
