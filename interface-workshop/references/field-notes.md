# Interface Workshop field notes

## Worked decision: registration has closed

A visitor on a phone follows an old ticket link. A tall countdown dominates the first screen and the purchase button still opens the expired form. Start by asking what the visitor can actually do. Keep the event identity, show “Registration closed” beside the date, and offer directions if the event is upcoming and the venue is confirmed. After the event, directions may cease to be useful. If there is no reasonable next action, stop at the status. Keep any start-time countdown subordinate and label what it counts down to.

Exercise: compare a fixed action bar with an inline link on this page using the same copy. Try reaching venue details with enlarged text, then returning with Back. Record which content each option covers and how many steps it takes. Choose using those observations. If both work equally well, the inline link costs less screen space.

## Transfer exercise: a map and a keyboard

On a small phone, let someone edit the destination while looking at alternatives. Sketch the reading order with the keyboard closed, then open. Where do suggestions appear? What keeps the selected route visible when the sheet closes? Test a long place name, no matches, and a delayed previous query arriving after the current one. Observe the selected destination at the end. A clean screenshot cannot answer that last question.
