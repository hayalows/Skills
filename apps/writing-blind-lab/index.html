How to make the test useful

Don't try to guess which version wrote each answer. Judge the actual sentence, as if you were about to post or send it. The six positions have been balanced across the 24 situations.

  1. Read the brief, then all six options before choosing.
  2. Pick A, B, C, D or none. If two are equally good, choose “Tie”.
  3. Rate each draft for “sounds like me” and “sounds natural” from 1 to 5. For a more thorough test, open “More ratings”.
  4. Flag invented details or changes to meaning even if the piece sounds good.
  5. Leave a note about a line you liked or disliked. This is especially valuable for future revisions.
  6. Keep reviewing. Answers save privately online after every change. Download a JSON backup only if you want an extra copy.
