# Papa Kojo Writing Blind Lab

A private **six-way** writing-preference pilot covering 24 identical briefs and 144 anonymous drafts. This is the same live website at https://pkm-writing-blind-lab.vercel.app/.

## Tested writing approaches

- v1.0 (original skill)
- v1.1 (anti-pattern rules and early tooling)
- v1.2 (context-first revision)
- v1.2 Refined / v1.2.1 (v1.2 calibrated to the **user-approved revised Word of Wisdom essay**; this is an experimental editorial variant, not a separately released full SKILL.md)
- v1.3 draft (experimental source)
- v1.4 draft (experimental source)

All 144 pilot drafts were prepared in a single model-assisted authoring process using the respective version's guidance and the same fixed task briefs. They were **not** generated by six isolated independent model runs. Any results are preferences for these particular drafts, not proof of which skill always performs best.

## Blind test design

Each question has six anonymous choices A–F. Their assignment to versions is shuffled per question and position-balanced: **each version appears exactly four times in each letter position across 24 questions**. The participant-facing GitHub file contains all six draft texts but no mapping between letter and version. The mapping and the reporting algorithm are stored server-side in the `pkm-blind-lab` Supabase Edge Function.

The study measures a first-choice preference (including the possibility of "none" or "tie"), two primary 1–5 ratings for every candidate (personal voice and natural reading), and optional ratings for truth, reader fit, flow and specificity. The reviewer can flag invented facts or changes in meaning and leave free-text comments. The "core 10" mode is a shorter route through the same 24-item study, not a separate database or separate version comparison.

## Privacy and interpretation

The public page contains the anonymous writing samples. Never add the sealed mapping, private URL access key, database service-role credential, private user correspondence or unapproved personal writing to this repository. Authorised reading of survey responses goes through the authenticated private endpoint or the connected Supabase account.

A balanced display reduces position bias but cannot eliminate differences in writing length, quality, format or the model's own preferences. The user's personal ratings are the reference for what sounds like them, but they should not be treated as universal performance or scientific authorship detection. A larger, isolated, new-prompt holdout is needed before claiming that a new skill produces more natural writing in general.
