# Test plan / acceptance conditions

1. Source baseline SHA matches GitHub `21b0e2a5989aab8842849f8e92ba622adb1975cc`.
2. Only one experimental writing procedure is added, and the approved baseline instructions remain intact.
3. Short tasks do not invoke the long-form map or force longer output.
4. No source facts, user identity or quotes are invented.
5. For long pieces, opening, middle and ending remain connected without repetitive recaps.
6. Existing mechanical test tools remain unmodified.
7. No self-assigned 100-point voice score. Ratings by the producing assistant are formative editorial observations only.
8. Inference is not an independent API experiment unless separate response IDs and identical settings are recorded.
9. Maintain v1.2.1 as the official version unless the owner explicitly approves promotion.
