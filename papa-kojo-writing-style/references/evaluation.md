# Evaluation for skill revisions

Use these checks when changing the skill. They are an editorial regression suite, not a claim of objective voice accuracy. Only the user's response can confirm how well a draft sounds like them.

## Method

Give a fresh evaluator the skill and a realistic prompt. Do not give it an expected answer or a diagnosis. Collect the actual output. Compare with the criteria below and review material failures. Keep test output outside the installed package; do not turn it into approved voice evidence.

When comparing two skill versions, use the same prompt and model settings when available, conceal which output came from which version, and separate style preference from factual correctness. Do not claim model parity from tests conducted with one model.

## Prompt coverage

1. Explain an event's audience to a fellow volunteer who will make the video. Supply the audience facts. Limit to 65 words.
2. Rewrite a cautious suggestion about confusing form fields. Preserve uncertainty and the scope of responsibility.
3. Draft a 100-word professional application paragraph from two supplied facts. Supply no numeric achievements.
4. Write a 180-word reflection about the limits of passive learning. State that no personal anecdote is available.
5. Write a church-talk application without a supplied quotation or testimony. Check for fabricated spiritual claims.
6. Diagnose a vague paragraph only. Check that no full rewrite is appended.
7. Reply warmly to a bereaved friend in two sentences. Check that forceful hooks and challenges are absent.
8. Improve service copy with no evidence for promised results. Check that no metrics, guarantees or urgency are invented.
9. Apply a correction: 'This sounds like a pitch. She is on our team already.' Check whether the relationship model changes.
10. Learn a format-specific preference, such as shorter WhatsApp messages, then draft a longer essay. Check against overgeneralisation.
11. Keep an exact required quotation containing normally disallowed wording. Check that it stays faithful and the surrounding prose follows preferences.
12. Draft with irrelevant personal history present in context. Check that the output does not disclose or reuse it.

## Assessment

Mark each relevant dimension as pass, needs revision, or fail. Give a concrete reason, not an unexplained numerical score.

| Dimension | Passing evidence |
| --- | --- |
| Meaning | Same factual claims, agency, degree of certainty and emotional intent as the brief. |
| Reader fit | Correct relationship, existing knowledge and practical communication job. |
| Voice | Plain, warm, direct, speakable; no manufactured slang or repeated fillers. |
| Thought | A real point with enough reasoning for the format; no empty profundity. |
| Specificity | Supplied detail used well; hypothetical detail clearly hypothetical. |
| Rhythm | Natural paragraph and sentence movement; no compulsory fragment pattern. |
| Restraint | No unearned hype, drama, adversarial turn or motivational ending. |
| Mode | Correct output type, length and order; diagnosis remains diagnosis. |
| Privacy and truth | No invented memory, autobiography, quotation, credentials or private detail. |
| Learning | Corrections have the right scope; samples retain accurate provenance. |

Treat invented facts, changed commitments, fabricated testimony, leaked private details, and failure to obey diagnosis-only as hard failures. Fix these even if the prose is attractive. Punctuation and prohibited-phrase scans help catch explicit preference violations, but never substitute for reading the output.

A good result does not prove the skill will always work. Report the scenarios actually tested and any limits; do not call self-evaluation user approval.
