# Archived: Papa Kojo Writing Style v1.2.1

This folder is a complete, unchanged copy of v1.2.1 ("v1.2 refined") as it stood on 18 November 2026, before v3.0 "Original" replaced it as the active version. Git commit `049d7fc` holds the same files.

The entry file is named `SKILL.v1.2.1.md` so agents and the skills directory do not load two copies of the same skill.

## To use v1.2.1 again

- **For one task:** tell the agent to read `versions/v1.2.1/SKILL.v1.2.1.md` and follow it instead of the main `SKILL.md`. Its links point to the `references/` and `scripts/` folders next to it.
- **To make it the default again:** copy this folder's contents back over the skill folder and rename `SKILL.v1.2.1.md` to `SKILL.md`, or check out `papa-kojo-writing-style` from commit `049d7fc`.

Nothing in this folder should be edited. New work goes into the main skill.
