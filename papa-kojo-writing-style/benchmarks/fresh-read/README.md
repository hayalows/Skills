# Reproduce a fresh writing comparison

1. Inventory runnable SKILL.md snapshots by commit. Keep older drafts as historical evidence when the underlying skill instructions cannot be recovered. Treat Threadline as a separate experiment unless it is explicitly a contestant.
2. Set the briefs, facts and rubric before running any version. Include an edit, a message, a personal statement and a reflective or professional piece. Keep final briefs with a separate author or evaluator. Public fixtures support reproduction. For a new unseen test, write fresh fixtures and withhold them from everyone editing the skill.
3. Begin each generation in a separate clean context. Use the same model, effort and briefs, loading only the candidate and its relevant references. Record the model, revision, date, number of runs and the length of each output. Use a JSON object mapping each brief ID to its output.
4. Run `python3 blind.py BRIEFS PACKET KEY DRAFT_A.json DRAFT_B.json --seed 274` and again with `--reverse` and different output paths. Keep the keys away from the judges. Have each judge rank every draft for each brief, allowing ties. Start with facts and task completion, then assess voice, reader fit, flow and word choice. Ask judges to give exact reasons. Treat model judgements as provisional. Papa's blind choices are the strongest available evidence for personal voice.
5. Decode only after votes close. Give tied candidates the mean of the positions they occupy. Report mean rank, disagreement across judges, sample size and critical factual failures. Keep the two rounds distinct. Do not use public benchmark winners as proof of general voice accuracy.
6. Send clean plain-text drafts to `python3 ../../scripts/reading_windows.py` from this directory. Review the overall grade estimate, then any difficult sentence windows. The 100-word/five-sentence reporting floor, 250-word windows and 125-word step are practical settings. They are not validated thresholds. The syllable counter is heuristic. Review short drafts by reading them aloud and checking what the recipient would need to guess.
7. For a 5,000- or 10,000-word test, use real long-form drafts and check early, middle and late windows. Repeated synthetic prose can test the checker but cannot establish good long-form writing. Archive private inputs and results only in a private location.

Sources for the method: [Purdue on connecting old and new information](https://owl.purdue.edu/owl/general_writing/mechanics/sentence_clarity.html), [CDC Clear Communication Index](https://www.cdc.gov/ccindex/pdf/clear-communication-user-guide.pdf), and [Zheng et al. on judging and position bias](https://arxiv.org/abs/2306.05685).
