# Default editorial design system

Use this system only when the user has not supplied a usable brand identity. Adapt its hierarchy to the user’s own identity when they have one.

## Palette

- Near-black text: `#111111`
- White or warm off-white background: `#F6F4F1`
- Accent: burnt orange `#F4511E`
- Secondary grey: `#BFC3C8`
- Light grey: `#E8EAED`
- Optional soft peach field: `#F4D8CC`

Use the accent to direct attention, not cover the page.

## Typography

Pair an editorial serif for titles with a clean sans-serif for text, charts, captions, and navigation. Suitable widely available options include Georgia, Source Serif 4, Libre Baskerville, or Cormorant Garamond with Arial, Inter, Aptos, Helvetica, or Source Sans 3.

Suggested A4 sizes:

- Cover: 42–64 pt serif
- Section title: 30–46 pt serif
- Main page claim: 20–30 pt
- Body: 10.5–12.5 pt
- Pull statistic: 42–76 pt
- Chart labels: 8.5–10 pt
- Sources and footnotes: 7.5–9 pt

Use a small, consistent type scale.

## Grid and visual language

For Editorial Report Mode, use a 12-column A4 portrait grid. Keep margins around 16–24 mm. Use deliberate asymmetry, exact alignment, generous whitespace, thin rules, oversized section numerals, direct chart labels, and small running headers/page numbers.

For Editorial Presentation Mode, use a 16:9 widescreen grid with wide safe margins. Let headline, evidence, and visual content occupy distinct zones. Make headlines and statistics large enough to read from the back of a room. Keep text blocks short and leave visible empty space around the dominant element.

Use cropped full-width images or soft tinted fields selectively. Avoid heavy shadows, gradients without purpose, decorative icon sets, many competing colours, rounded cards everywhere, excessive borders, and generic image collages.

## Page types

Use a coherent mix, not the same layout repeated mechanically:

1. Cover
2. Contents
3. Executive summary
4. Section opener
5. Insight page
6. Data page
7. Statistic-led page
8. Photograph plus narrative
9. Conclusion and next steps
10. Methodology and sources

Make every page or slide answer one question: **What is the single most important thing the reader should notice here?**
